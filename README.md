# NFL Analytics & Game Prediction Platform

A full-stack NFL analytics application that uses historical play-by-play data, advanced football metrics, and machine learning to predict NFL game outcomes.

## Live Demo

https://nfl-analytics-zeta.vercel.app

## Overview

This project combines NFL data analysis, machine learning, backend API development, and frontend development into one application.

Users can select an NFL season, week, and matchup to receive a predicted winner and win probabilities generated by a trained machine learning model.

The application also handles early-season predictions by blending prior-season performance with current-season data as more games are played.

## Features

- Browse NFL matchups by season and week
- Generate predicted winners and win probabilities
- Analyze offensive and defensive team performance
- Elo rating system
- EPA per play
- Passing and rushing efficiency
- Turnover differential
- Recent team performance
- Home and away performance
- Rest and bye-week features
- Early-season prior/current season blending
- Automatic fallback when current-season data is unavailable
- REST API built with FastAPI
- Interactive React frontend
- Deployed frontend and backend

## Machine Learning

The project evaluates multiple machine learning models, including:

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- Soft Voting Ensemble

The deployed prediction model currently uses Logistic Regression with feature scaling.

### Model Performance

Rolling historical evaluation:

| Season | Logistic Regression Accuracy |
|--------|------------------------------|
| 2023 | 55.1% |
| 2024 | 64.8% |
| 2025 | 63.1% |

Overall rolling accuracy across 2023–2025:

**61.0%**

The evaluation process trains only on seasons prior to the season being tested to reduce data leakage.

## Early-Season Predictions

Early in the NFL season, current-season statistics are based on very small sample sizes.

The application gradually blends prior-season and current-season performance:

- 1 game played: 75% prior season / 25% current season
- 2 games played: 50% prior season / 50% current season
- 3 games played: 25% prior season / 75% current season
- 4+ games played: current-season data

Week 1 predictions use prior-season information because no current-season games have been played yet.

## Run Locally

### Backend

Create and activate a Python virtual environment, install dependencies, and run:

```bash
pip install -r requirements.txt
uvicorn api:app --reload
```

### Frontend

Open a second terminal and run:

```bash
cd frontend
npm install
npm run dev
```

Create a `.env.local` file inside the `frontend` folder with:

```text
VITE_API_URL=http://127.0.0.1:8000
```

Then open:

```text
http://localhost:5173
```
